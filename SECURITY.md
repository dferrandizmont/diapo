# Security

If you find a security or privacy issue in Diapo, please write to
**diapo@mainshai.com** instead of opening a public issue. Include the app
version, your phone model and Android version, the steps to reproduce the
problem and its possible impact, so it can be reviewed and fixed before it is
made public.

Diapo has no accounts, no servers and no internet permission, so the most
useful reports are about photos reaching places they should not: an
undeveloped roll that can be read outside the app's encrypted storage, a photo
or its location leaking into another app, or a build that declares a permission
it does not need.

Please do not attach photos of real people. Reproduce the problem with test
shots.
