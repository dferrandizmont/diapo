# Contributing

Thank you for wanting to help with Diapo.

- **Issues are welcome.** Bug reports, film ideas and translation fixes help a
  lot. Use the issue forms; for security or privacy problems, write to
  diapo@mainshai.com instead (see [SECURITY.md](SECURITY.md)).
- **Pull requests are not accepted yet.** Diapo has a single author for now, so
  that the copyright of the code stays with one person. A pull request will be closed without merging; if you found a fix, describe it
  in an issue and it will be credited in the changelog.

The code is under the [GNU General Public License v3.0 only](LICENSE): you can
fork it, change it and share your version under the same licence. The name
"Diapo", the app icon and the screenshots are not covered by that licence; a
fork must use its own name and icon.

---

Gracias por querer ayudar con Diapo. Las incidencias son bienvenidas (fallos,
ideas de películas, correcciones de traducción); de momento no se aceptan pull
requests. Para problemas de seguridad o privacidad, escribe a
diapo@mainshai.com.
